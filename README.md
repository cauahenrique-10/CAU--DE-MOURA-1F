## O que tem aqui

Cada etapa tem um arquivo `.html` e um arquivo `.js` com o mesmo nome. Por exemplo, `etapa-2.html` carrega o `etapa-2.js`.

| Arquivos | Conteúdo 
| etapa-0.html e etapa-0.js | Preparando o ambiente: primeiro console.log |
| etapa-1.html e etapa-1.js | O que é JavaScript: expressões no console |
| etapa-2.html e etapa-2.js | Variáveis e tipos (`let`, `const`, `typeof`) |
| etapa-3.html e etapa-3.js | Operadores, conversão com Number() e template literals |
| etapa-4.html e etapa-4.js | Condicionais (`if`, `else if`, `else`, `===`) |
| etapa-5.html e etapa-5.js | Laços `for` e listas |
| etapa-6.html e etapa-6.js | Funções (`return`, arrow function) |
| etapa-7.html e etapa-7.js | DOM e eventos: contador de cliques |
| etapa-8-1 a etapa-8-5 (.html e .js) | Mini-projeto: calculadora de média, em partes (8.1 página, 8.2 esqueleto, 8.3 média, 8.4 validação, 8.5 completo) |
| index.html | Página inicial com links para todas as etapas |
| respostas.md | Respostas escritas dos checkpoints de todas as etapas |

Na `etapa-2`, o erro `Assignment to constant variable` na última linha é proposital: faz parte do exercício.
